# Examen II - Aplicación de Técnicas de Minería de Datos.

<h1 align="center">Reglas de Asociación y CRISP-DM 🛒📊🔎</h1>

Este proyecto corresponde al **Examen Parcial II** del curso Minería de datos II (BD-162). Se integran todas las fases del ciclo de vida de un proyecto de minería de datos siguiendo la metodología CRISP-DM: exploración, limpieza, transformación y modelado, para tomar decisiones de negocio basadas en los datos.

El análisis se orienta a dos ejes:

- **Análisis exploratorio y estadístico**: estadísticas descriptivas para identificar comportamientos, distribuciones y anomalías.
- **Minería de patrones y reglas de asociación**: implementación de **Apriori**, **Eclat** y **FP-Growth**, y construcción de un **sistema de recomendación** a partir de las reglas encontradas.

## 📄 Dataset utilizado

| Dataset | Fuente |
|---------|--------|
| **Online Retail** | https://archive.ics.uci.edu/dataset/352/online+retail |

Conjunto de datos transaccional de una tienda en línea con sede en el Reino Unido (sin tienda física), que vende principalmente regalos para toda ocasión. Muchos de sus clientes son mayoristas.

| Característica | Detalle |
|----------------|---------|
| Registros | 541.909 |
| Periodo | 01/12/2010 al 09/12/2011 |
| Variables | `InvoiceNo`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `UnitPrice`, `CustomerID`, `Country` |
| Archivo original | `Online Retail.xlsx` (22,6 MB) |
| Licencia | CC BY 4.0 |
